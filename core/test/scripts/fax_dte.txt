# class 1 fax, what the DTE sends around <DLE><ETX> (T.31 8.3.3, 8.3.5):
# B (answering, in +FTH after CED) sends CSI and DIS in one write, each
# frame on its own; A ends an +FTH with an empty frame (OK); A's +FTM data
# and its next command in one write (the command is kept: the core runs
# it with the DTE's next characters).  core_equiv's FaxDteUntilsCome:
# every until here comes.
