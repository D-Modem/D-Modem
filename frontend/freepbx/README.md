# D-Modem for FreePBX

This folder contains the FreePBX module (`dmodem/`). The module has these
parts:

- The profiles of D-Modem as destinations in FreePBX.
- `dmodem.conf` and the dialplan that the module writes for the profiles.
- A check of the PJSIP endpoints for modem calls.

Refer to [docs/freepbx.md](../docs/freepbx.md).
