# Open data pumps for D-Modem

This folder contains the open DSP. It has V.21 to V.34, V.90 (digital modem), V.91, V.92 and class 1 fax. The open DSP uses the C interface of the original DSP library of Smart Link (`dsplibs.h`). For a description of how it operates, refer to [docs/dsp/](../docs/dsp/README.md). For its tests, refer to [docs/testing.md](../docs/testing.md) and [docs/interop.md](../docs/interop.md).
