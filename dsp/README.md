# Open data pumps for slmodemd

The open DSP: V.21 to V.34, V.90 (digital modem), V.91, V.92 and class 1 fax, behind the C interface of Smart Link's original DSP library (`dsplibs.h`). See [docs/dsp/](../docs/dsp/README.md) for how it works, and [docs/testing.md](../docs/testing.md) and [docs/interop.md](../docs/interop.md) for its tests.
