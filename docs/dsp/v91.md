# V.91: digital to digital

V.90 has one digital end and one analogue end. **V.91** is for calls where
the two modems are on digital lines. An example is two D-Modems that call
each other through SIP or through Asterisk. No end has an analogue line.
Thus, the two directions can use the fast digital method. This gives about
62000 bit/s in each direction.

The code is `dsp/v91.cpp`. For the start-up steps, the retrain rules and
the measured rates, refer to [the technical details](v91-details.md).

## How it starts

During V.8, the two modems tell that they can do V.91. If V.91 does not
start after this, they fall back to V.34. On a 4-wire digital leased
circuit (`AT&L2+MS=V91`, refer to [leased lines](../leased.md)), V.91
starts immediately with no V.8.

## Speeds

| Network | Speed |
|---|---|
| clean G.711, µ-law or A-law | 62667 bit/s |
| with "robbed bits" (some American trunks) | 61333 bit/s |
| with a 3 dB volume pad | 60000 (µ-law) or 61333 (A-law) bit/s |
| converted between µ-law and A-law on the path | 62667 bit/s |

With error correction enabled, about 58700 bit/s of real data goes
through. For V.34, this value is about 31400 bit/s.

If the line becomes worse, the modems retrain. Then error correction sends
again the data that was lost.
