# V.26 ter: 2400 bit/s on a dial-up line

**V.26 ter** is the ITU's 2400 bit/s modem for ordinary phone lines,
from 1984. Both ends send at the same time on the same pair of wires,
each on the same 1800 Hz carrier, and each modem removes its own echo
from what it hears (echo cancelling), as V.32 does later at higher
speeds. It falls back to 1200 bit/s on a poor line. It was used mostly
in France and in Europe; elsewhere V.22bis did the same job.

D-Modem has V.26 ter from the Recommendation's text. Two D-Modems
connect with it at 2400 or 1200 bit/s. There are no V.26 ter modems in
D-Modem's interop tests, so it has not been tried against another
maker's.

Its older relatives:

- **V.26** (and Bell 201, its "alternative B") are 2400 bit/s modems
  for 4-wire leased lines. D-Modem has them (`AT&L2+MS=V26`, see
  [leased lines](../leased.md)).
- **V.26 bis** is the half-duplex dial-up version (one end talks at a
  time). It is not done yet.

For the full technical description, see
[the technical details](v26-details.md).

## Using it

    AT+MS=V26T       (or AT+MS=126, or AT+MS=V26TER)

Both ends need it: V.26 ter starts with an answer tone and its own
handshake, not V.8, so a modem that is not set to it will not find it.
`AT+MS=V26T,0,1200,1200` keeps the call at 1200 bit/s.

The start-up takes about 7 seconds after the answer tone:

1. The answering modem says which speeds it can do.
2. The calling modem picks one and says so.
3. Each modem in turn sends for a second so that its echo canceller
   can learn its own echo.
4. Both send at once, and the data starts.

V.26 ter has no retrain: a line that gets too bad ends the call.

## In simulation

Two D-Modems back to back on a simulated phone line (`pump_test` and
`dmodem_test`) connect at 2400 bit/s:

| Line | Result |
|---|---|
| clean | 2400 bit/s, no errors |
| 15 dB signal to noise | 2400 bit/s, no errors |
| each modem's own echo 6 dB below its signal | 2400 bit/s, no errors (the canceller takes away 28 dB) |
| 8000 Hz sampling, a 4x level change, a 300 ppm clock difference | 2400 bit/s, no errors |
| `AT+MS=V26T,0,1200,1200` | 1200 bit/s |
