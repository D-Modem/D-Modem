# V.70: voice and data on one call (DSVD)

**V.70** (ITU-T V.70, "DSVD", digital simultaneous voice and data) lets
two modems carry a telephone conversation and a data connection at the
same time on one call. The voice is compressed (G.729 Annex A, 8 kbit/s)
and sent as data, side by side with the computer's own data, over one
V.34 (or faster) connection. In the mid-1990s it was sold as "talk while
you play" for modem games and remote help.

The parts that make it up are:

- **V.8bis**, where the two modems agree to use DSVD at the start of the
  call ([V.8bis](dsp/v8bis.md));
- **V.76**, a multiplexer that shares the connection between several
  channels (one for data, one for voice);
- **V.75**, which opens and closes those channels;
- G.729 Annex A, the voice coder.

D-Modem is building V.70 in stages. The first stage was V.8bis. This
second stage is the multiplexer and its channel control, with the data
channel: two D-Modems agree on DSVD, connect, and the computer's data
goes over V.76's data channel. The voice channel (G.729 Annex A) is the
next stage.

For the full technical description, see
[the technical details](v70-details.md).

## Turning it on

Both ends need V.8bis and DSVD on:

    AT+A8E=1,1,,1+DSVD=1

`+DSVD` is D-Modem's own command: `1` offers DSVD in V.8bis and chooses
it when the other end offers it too, `0` (the default) does not.
`AT+DSVD?` shows the setting.

With DSVD on at one end only, the call goes on as a plain data call
with V.42 error correction, as it would without it.

## What the user sees

`ATD` and `ATA` work as usual. `CONNECT` comes once the data channel is
open, and the computer's data flows as on any error-corrected call.
Where the modem names the call's error correction (`ATI11`, the
`Protocol:` report), it says `V.76`. There is no compression on the data
channel.

## Limits

- No voice yet: only the data channel is opened. The voice channel comes
  with the next stage.
- Only between two D-Modems so far; it has not been tried against
  another maker's DSVD modem.
- DSVD runs over whatever modulation V.8 then picks. V.70 names V.34
  and V.32bis; two D-Modems on a digital line pick V.91 (up to 62667 bps)
  instead.
- DSVD is only agreed at the start of a call, not in the middle of a
  telephone conversation.
- One data channel, in error-recovery mode, with V.76's default
  settings. A channel the other end asks for with other settings, a
  second data channel, or a voice channel is refused.
