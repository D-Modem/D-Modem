# T.85: JBIG for fax pages

This page describes ITU-T Recommendation T.85 (08/95), "Application
profile for Recommendation T.82 – Progressive bi-level image
compression (JBIG coding scheme) for facsimile apparatus". It is our
own description. It is not a copy of the Recommendation. For the
normative text, refer to the Recommendation (`docs/specs/fetch.sh
T.85`). For the parameters, refer to [the technical
details](t85-details.md).

## Summary

T.85 tells how a Group 3 or Group 4 fax machine uses [T.82](t82.md)
(JBIG) for bi-level pages.

- A fax page is one BIE. It uses single-progression sequential coding:
  one layer, one bit-plane, no progressive coding.
- The basic stripe is 128 lines (L0). Other values are an option that
  the fax procedure negotiates.
- The page length can be unknown at the start. The sender then gives
  the length at the end with a NEWLEN marker segment.
- T.30 negotiates T.85 with DIS/DCS bits 78 and 79. T.85 needs ECM.

## Where T.85 is used

Some fax machines and fax servers use T.85 for pages with halftone
images, because it codes them better than MMR.

## T.85 in D-Modem

The T.30 machine (`dsp/t30.cpp`) sends and receives T.85 pages with
ECM. `dsp/jbig.cpp` codes the pages.
