# T.44: mixed raster content

This page describes ITU-T Recommendation T.44 (01/2005), "Mixed Raster
Content (MRC)". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh T.44`). For the data structure, refer to [the
technical details](t44-details.md).

## Summary

T.44 divides a page into layers, and codes each layer with the coding
that is best for it.

- The base mode (mode 1) has three layers. The mask is bi-level (MH,
  MR, MMR or JBIG). The foreground and the background are colour or
  grey images (JPEG or T.43). Where the mask is 1, the foreground
  shows. Where it is 0, the background shows.
- Text goes in the mask at full resolution. Its colour goes in the
  foreground. A photograph goes in the background, at a lower
  resolution if necessary.
- The page is a set of horizontal stripes. Each stripe tells which
  layers it has. A layer that is not there is one colour.
- The data uses JPEG markers. The start of page (SOP) starts with SOI.
  A SOSt starts each stripe. Two EOIs end the page.
- Mode 2 (Annex A) puts a start of layer (SLC) and an end of header
  (EOH) before the coded data of each layer. The SLC gives the coder,
  the resolution, the size, the colour and the offset of the layer.
- Mode 3 (Annex A) adds more pairs of a mask and an image (layers 4
  and 5, 6 and 7, and more). Each image shows through its mask, on top
  of the layers below it.
- Mode 4 (Annex B) adds data that layers and pages can share, JBIG2
  masks and colour tags (T.45).

## Where T.44 is used

Colour fax machines use T.44 for pages with text and pictures. The page
is smaller than in JPEG, and the text stays sharp.

## T.44 in D-Modem

`dsp/t44.cpp` codes and decodes T.44 pages in modes 1, 2 and 3. In
mode 3, the encoder puts text of a small number of flat colours in one
mask for each colour, with no foreground image. The T.30 machine sends
a page with colour text in T.44 mode 1 when the far end supports it.
