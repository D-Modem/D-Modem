# V.59: managed objects for diagnostic information

This page describes ITU-T Recommendation V.59 (11/2000), "Managed
objects for diagnostic information of public switched telephone network
connected V-series modems". It is our own description. It is not a copy
of the Recommendation. For the normative text, refer to the
Recommendation (`docs/specs/fetch.sh V.59`). For the objects and their
values, refer to [the technical details](v59-details.md).

## Summary

V.59 gives the objects that a modem keeps about its last connection.
The DTE reads them after the call, to find why a connection was bad.

- Each object has a name and a tag of four hexadecimal digits. The high
  two digits give the high-level object, for example 0C for V.34. The
  low two digits give the object.
- The tags 40 to 5F in the low digits are the common objects. All the
  modulations can have them, for example the transmit power (47).
- Each value is text: a number, a code from a table, a level with its
  unit, TRUE or FALSE, a bit string in hexadecimal, or NULL.
- Some objects are mandatory. An object that needs more processing in
  the DCE is usually optional.

## Where V.59 is used

The V.250 command `+TMO` (V.250 6.9) reads the objects.
