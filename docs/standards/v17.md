# V.17: 14400 bit/s fax modem

This page describes ITU-T Recommendation V.17 (02/91), "A 2-wire modem
for facsimile applications with rates up to 14 400 bit/s". It is our own
description. It is not a copy of the Recommendation. For the normative
text, refer to the Recommendation (`docs/specs/fetch.sh V.17`). For the
signal, the training sequences and the timing, refer to [the technical
details](v17-details.md).

## Summary

V.17 sends fax data at 14400, 12000, 9600 or 7200 bit/s, in half duplex
on the telephone network.

- The carrier is 1800 Hz. The modem sends 2400 symbols each second.
- All the rates use the trellis code and the points of
  [V.32 bis](v32bis.md). At 14400 bit/s, each symbol carries six bits on
  128 points.
- A scrambler makes the data random.
- Before the data, the modem sends a training sequence. The long train
  (1393 ms) is for the first page and for a retrain. The short train
  (142 ms) is for the next pages, when the receiver keeps its equalizer.
- An optional signal (TEP) before the training protects the receiver
  from talker echo.

## Where V.17 is used

V.17 is the fastest modulation of Group 3 fax before V.34. T.30 selects
it in the DCS signal. The fax procedure supplies the rules for the
switched network and the rate.

## Related standards

- [V.32 bis](v32bis.md): the same trellis code and points.
- [V.33](v33.md): the same signal, duplex on 4-wire leased lines.
- [V.29](v29.md) and [V.27 ter](v27ter.md): the slower fax modulations.
- [V.21](v21.md): channel 2 sends the T.30 signals between the pages.
- T.30: the fax procedure.

## V.17 in D-Modem

`dsp/fax_modems.cpp` has the V.17 transmitter and receiver. The fax code
uses them for the pages. In Class 1, `AT+FTM=145` and `AT+FRM=145`
select 14400 bit/s with the long train. `AT+FTM=146` selects the short
train. The codes 73, 97 and 121 (and 74, 98 and 122) select the other
rates.
