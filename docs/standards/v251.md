# V.251: AT commands for V.8 and V.8 bis

This page describes ITU-T Recommendation V.251 (02/98), "Procedure for
DTE-controlled call negotiation". It is our own description. It is not
a copy of the Recommendation. For the normative text, refer to the
Recommendation (`docs/specs/fetch.sh V.251`). For the commands and the
indications, refer to [the technical details](v251-details.md).

## Summary

V.251 gives AT commands that let the computer see or control the start
of a call with V.8 and V.8 bis.

- `AT+A8E` sets who controls V.8 and V.8 bis: the modem (DCE control) or
  the computer (DTE control).
- With DCE control, the modem does V.8 itself. It can also report each
  V.8 signal to the computer with `+A8` indications.
- With DTE control, the computer reads each signal that the modem
  receives (ANSam, CI, CM, JM, CJ). Then it tells the modem which CM or
  JM to send (`AT+A8M`). For V.8 bis, it sends signals and messages
  with `AT+A8T`, and it receives them as `+A8R`.
- The octets of CI, CM and JM go as hexadecimal characters.

## Where V.251 is used

H.324 videophones, fax software and V.18 text telephones use V.251 when
they must select the call function themselves.

## Related standards

- V.8 and V.8 bis: the procedures that these commands control.
- V.250: the syntax of the commands.
- T.31: the class 1 fax commands, which use V.8 for V.34 fax.

## V.251 in D-Modem

`core/at.cpp` has `AT+A8E`. `core/modem.cpp` sends the `+A8`
indications. The modem always controls V.8 and V.8 bis itself. The
commands are described in [the AT commands](../at_commands.pdf).
