# V.75: the control of DSVD

This page describes ITU-T Recommendation V.75 (08/96), "DSVD terminal
control procedures". It is our own description. It is not a copy of
the Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh V.75`). For the messages and the audio header,
refer to [the technical details](v75-details.md).

## Summary

V.75 is the control entity of a [V.70](v70.md) terminal. It opens,
closes and sets the parameters of the channels of the [V.76](v76.md)
multiplexer.

- To open a channel, V.75 puts an H.245 OpenLogicalChannel message in
  the SABME of the DLC. The UA carries OpenLogicalChannelAck. A DM
  carries OpenLogicalChannelReject.
- To close a channel, the DISC carries CloseLogicalChannel. The UA
  carries CloseLogicalChannelAck.
- A TerminalCapabilitySet message in an XID frame sends the
  capabilities. The answer is TerminalCapabilitySetAck or
  TerminalCapabilitySetReject.
- Each H.245 message starts with the format identifier 133.
- A voice frame can start with a 1-octet audio header: a silence bit, a
  SID bit and a sequence number.
- On an ERM data channel, V.75 sends a break of the DTE.

## Related standards

- [V.70](v70.md): DSVD.
- [V.76](v76.md): the multiplexer.
- H.245: the messages, in the aligned PER of X.691.
