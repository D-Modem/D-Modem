# V.54: loop test devices for modems

This page describes ITU-T Recommendation V.54 (11/88), "Loop test devices
for modems". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh V.54`). For the loops and the signals, refer to
[the technical details](v54-details.md).

## Summary

V.54 gives loops that send a signal back to where it came from. With a
loop, you can find the part of a data circuit that has a fault.

- Loop 1 is in the DTE. It sends the transmitted data back to the DTE.
- Loop 3 is the local analogue loop. The signal of the modem goes back
  into its own receiver. No signal goes to the line.
- Loop 2 is the remote digital loop. The far modem (DCE B) sends the
  data that it receives back to the near modem (DCE A).
- Loop 4 is on a 4-wire line. It connects the two pairs together, for
  analogue measurements.

A switch on the modem, the interface circuits 140 and 141, or a signal
in the data can start a loop. The signal in the data has four phases:

1. Preparatory: DCE A sends a pattern that asks for the loop.
2. Address: DCE B sends an acknowledgement and closes loop 2.
3. Test: DCE A sends test data, and the data comes back.
4. Termination: DCE A sends a pattern that opens the loop.

## Where V.54 is used

Leased line modems and many dial-up modems have the loops of V.54. The
AT commands `AT&T` and `+TRDL` operate them.

## Related standards

- [V.52](v52.md): the 511-bit test pattern for the loops.
- [V.22](v22.md) and [V.22 bis](v22bis.md): their own signals for loop 2.
- V.58: the test objects of a DCE (`+T` commands of
  [V.250](v250.md)).
