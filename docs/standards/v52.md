# V.52 and O.153: the 511-bit test pattern

This page describes ITU-T Recommendation V.52 (11/72), "Characteristics
of distortion and error-rate measuring apparatus for data transmission",
and the pattern of ITU-T Recommendation O.153 (10/92), "Basic parameters
for the measurement of error performance at bit rates below the primary
rate". It is our own description. It is not a copy of the
Recommendations. For the normative text, refer to the Recommendations
(`docs/specs/fetch.sh O.153`). ITU-T does not have a PDF of V.52 to
download. For the pattern and the checker, refer to
[the technical details](v52-details.md).

## Summary

V.52 gives a pseudo-random pattern for error-rate measurements on a data
circuit. O.153 gives the same pattern, and more rules for the measuring
equipment.

- The pattern has 511 bits. A shift register of nine stages makes it,
  with the polynomial x^9 + x^5 + 1.
- The transmitter sends the pattern in place of the data.
- The receiver makes the same pattern, and compares it with the received
  bits. Each bit that is different is a bit error.
- The receiver synchronises with the received pattern. It synchronises
  again when the errors are too many.

## Where V.52 is used

Modem self-tests use the pattern on a loop of [V.54](v54.md). The
V.250 command `+TTER` counts the bit errors and the block errors.

## Related standards

- [V.54](v54.md): the loops.
- [V.22](v22.md): its self-test uses reversals, not this pattern.

## V.52 in D-Modem

`AT&T7` and `AT&T8` send the pattern on loop 2 and loop 3. `AT&T0` gives
the number of bit errors. The code is `core/v54.h`.
