# T.32: Class 2 fax AT commands

This page describes ITU-T Recommendation T.32 (08/95), "Asynchronous
facsimile DCE control, service class 2". It is our own description. It
is not a copy of the Recommendation. For the normative text, refer to
the Recommendation (`docs/specs/fetch.sh T.32`). For the commands, the
reports and the parameters, refer to [the technical details](t32-details.md).

## Summary

T.32 gives the AT commands that let fax software use a modem that does
the procedure of [T.30](t30.md) itself. This mode is Class 2.0. The
software sends and receives only the page data.

- `AT+FCLASS=2.0` selects Class 2.0.
- `ATD` and `ATA` start the call. The modem reports the remote
  capabilities and identity, for example `+FCO`, `+FCI:` and `+FIS:`.
- `AT+FDT` sends a page. The software sends the page data, then
  `<DLE><ppm>` to tell if more pages come.
- `AT+FDR` receives a page. The modem gives the page data, then
  `+FPS:` (the page status) and `+FET:` (the post-page message).
- `+FHS:` gives the status at the end of the call.
- Parameters set the capabilities (`+FCC`, `+FIS`), the identity
  (`+FLI`), the reports (`+FNR`) and other options.
- In Class 2.0, numbers are hexadecimal.

## Where T.32 is used

Fax software such as HylaFAX and many Windows fax programs use
Class 2.0. Older software uses Class 2. Class 2 is the draft of
EIA/TIA-592 (SP-2388), with other names for the same commands.

## T.32 in D-Modem

`dsp/fax_class2.cpp` has the Class 2 and Class 2.0 engine.
`core/at.cpp` has the commands. The engine uses the T.30 machine of
`dsp/t30.cpp`, also on T.38 and on V.34.
