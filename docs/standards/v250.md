# V.250: AT commands

This page describes ITU-T Recommendation V.250 (07/2003), "Serial
asynchronous automatic dialling and control". It is our own description.
It is not a copy of the Recommendation. For the normative text, refer to
the Recommendation (`docs/specs/fetch.sh V.250`). For the syntax, the
commands and the result codes, refer to [the technical
details](v250-details.md).

## Summary

V.250 tells how a computer controls a modem with lines of text. Before
V.250, the modems of Hayes and of other companies used these "AT
commands", and V.250 made them a standard.

- Each command line starts with `AT` and ends with a carriage return
  (S3). A line can have many commands.
- The modem answers each line with a result code: `OK`, `ERROR`,
  `CONNECT`, `NO CARRIER` and others. With `ATV1`, the result codes are
  words. With `ATV0`, they are numbers.
- Basic commands have one letter, for example `ATD` (dial), `ATA`
  (answer) and `ATH` (hang up). S-parameters are numbered registers, for
  example `ATS0=2` (answer on the second ring).
- Extended commands start with `+`, for example `AT+MS` (the
  modulation), `AT+ES` (error control) and `AT+DS` (compression). A
  parameter has a read form (`?`) and a test form (`=?`).
- In a call, the modem sends the data of the computer to the line. The
  escape sequence `+++` with a guard time before and after it puts the
  modem back in command state. `ATO` goes back to the call.
- Before CONNECT, the modem can report the modulation, the error control
  and the compression of the call, if the computer asks for it.

## Where V.250 is used

Nearly all modems for the telephone line have AT commands. Fax (T.31,
T.32), voice (V.253) and V.8 control (V.251) use the same syntax.

## Related standards

- V.251: the AT commands for V.8 and V.8 bis.
- V.253: the AT commands for voice.
- V.80: synchronous access mode, which `AT+ES` and `AT+ESA` start.
- T.31: the AT commands for class 1 fax.
- V.58 and V.59: the test objects and diagnostics that `AT+T` and
  `AT+TMO` read.

## V.250 in D-Modem

`core/modem.cpp` sends the result codes. The commands of D-Modem are
described in [the core](../core.md) and [its technical
