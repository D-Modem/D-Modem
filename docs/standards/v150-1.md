# V.150.1: modem over IP

This page describes ITU-T Recommendation V.150.1 (01/2003), "Modem-over-IP
networks: Procedures for the end-to-end connection of V-series DCEs".
It is our own description. It is not a copy of the Recommendation. For
the normative text, refer to the Recommendation (`docs/specs/fetch.sh
V.150.1`). For the messages and the procedures, refer to
[the technical details](v150-1-details.md).

## Summary

V.150.1 connects two modems through an IP network. Each modem calls a
gateway on the telephone network, and the two gateways talk over IP.

- **Voice band data (VBD):** the gateways send the audio of the modems
  as G.711 RTP packets. V.152 tells how.
- **Modem relay (MR):** each gateway terminates the modulation and the
  error correction of its own modem. Then it sends only the data to the
  other gateway. This is more tolerant of packet loss and delay than
  VBD.
- **State signalling events (SSE, Annex C):** RTP packets that tell the
  other gateway to change between audio, VBD and modem relay, and why.
- **SPRT (Annex B):** a reliable transport on UDP. It has four channels:
  one for acknowledgements, one for data, one for control, and one
  without retransmission.
- **IP-TLP messages (clause 15.4):** INIT, JM_INFO, CONNECT, CLEARDOWN
  and others for control, and I_OCTET and others for data.
- **Trans-compression (TCX):** a gateway can undo the compression of
  its modem (D-TCX or S-TCX), or let it pass (N-TCX).
- **SDP (Annex E):** the attributes that offer and accept modem relay in
  a SIP call.

## Where V.150.1 is used

Secure telephone units (V.150.1 with SCIP) and modem calls through VoIP
networks use V.150.1. Many VoIP networks have only VBD.

## Related standards

- [V.8](v8.md): the CM and JM sequences that V.150.1 relays.
- [V.42](v42.md): the error correction that each gateway terminates.
- V.152: voice band data over IP.
- RFC 2833 (now RFC 4733): the events for the answer tones.

## V.150.1 in D-Modem

`dmodemd` on SIP is a modem relay endpoint (U-MR). It is the modem and
its gateway in one unit. The code is in `frontend/dmodemd/v150.cpp`.
For how to use it, refer to [modem relay](../v150.md).
