# V.33: 14400 bit/s on 4-wire leased lines

This page describes ITU-T Recommendation V.33 (11/88), "14 400 bits per
second modem standardized for use on point-to-point 4-wire leased
telephone-type circuits". It is our own description. It is not a copy of
the Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh V.33`). For the signal, the synchronizing signal
and the rate signal, refer to [the technical details](v33-details.md).

## Summary

V.33 sends data at 14400 bit/s, with a fallback rate of 12000 bit/s. It
was made for 4-wire leased circuits of special quality.

- Each direction has its own pair of wires. The modem sends in duplex
  with a continuous carrier.
- The carrier is 1800 Hz. The modem sends 2400 symbols each second.
- The two rates use the eight-state trellis code. At 14400 bit/s, each
  symbol carries six bits on 128 points.
- A scrambler makes the data random.
- The synchronizing signal trains the equalizer of the far receiver. It
  contains a rate signal that gives the rates of the modem.
- An optional multiplexer can put channels of 12000, 9600, 7200, 4800
  and 2400 bit/s into one stream.

## Where V.33 is used

V.33 is for leased lines. V.17 and V.32 bis use its trellis code and its
points.

## Related standards

- [V.17](v17.md): the same signal, in half duplex for fax.
- [V.32 bis](v32bis.md): the same trellis code and points on the
  switched network.
- [V.29](v29.md): the 9600 bit/s modem for the same leased lines.

## V.33 in D-Modem

`dsp/dp_4wire.cpp` has the V.33 data pump, on the V.17 transmitter and
receiver of `dsp/fax_modems.cpp`. `AT&L2` selects a 4-wire leased line,
and `AT+MS=V33` selects V.33.
