# T.30: the procedures of a Group 3 fax call

This page describes ITU-T Recommendation T.30 (09/2005), "Procedures
for document facsimile transmission in the general switched telephone
network". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh T.30`). For the phases, the frames, the bits and
the timers, refer to [the technical details](t30-details.md).

## Summary

T.30 gives the procedure of a fax call, from the call set-up to the
release of the line.

- A call has five phases: A (the call set-up), B (the negotiation and
  the training), C (the pages), D (the end of each page) and E (the
  release of the call).
- The caller sends CNG. The answerer sends CED, then
  its capabilities in DIS. The caller selects the mode in DCS, then
  sends TCF to check the line at the selected rate.
- The control messages are HDLC frames on V.21 channel 2 at 300 bit/s.
  The pages go on [V.27 ter](v27ter.md), [V.29](v29.md) or
  [V.17](v17.md), or on [V.34](v34.md) half-duplex.
- After each page, the sender tells if more pages come (MPS, EOM or
  EOP). The receiver tells if the page is good (MCF, RTP or RTN).
- Annex A gives the error correction mode (ECM). The sender sends the
  page in blocks of numbered frames. The receiver asks again for the
  frames that it did not receive (PPR).
- Timers and repeat counts make sure that a call that fails ends.

## Where T.30 is used

All Group 3 fax machines and fax modems use T.30. T.38 carries the
same procedure over IP.

## Related standards

- [T.4](t4.md) and [T.6](t6.md): the coding of the pages.
- [V.21](v21.md): the modulation of the control messages.
- [V.27 ter](v27ter.md), [V.29](v29.md), [V.17](v17.md) and
  [V.34](v34.md): the modulations of the pages.
- [V.8](v8.md): starts a V.34 fax call.
- T.82, T.85, T.42, T.43, T.44 and T.434: the other coding modes and
  file transfer, with ECM.
- T.31 and T.32: the AT commands for a fax modem.

## T.30 in D-Modem

`dsp/t30.cpp` has a full fax machine: sender and receiver, polling,
ECM, V.34 fax, and T.38. The Class 2 and Class 2.0 commands
(`dsp/fax_class2.cpp`) and the fax mode of `dmodemd` use it. With
Class 1, the fax software on the host does T.30.
