# T.43: lossless colour and grey-scale fax

This page describes ITU-T Recommendation T.43 (07/97), "Colour and
gray-scale image representations using lossless coding scheme for
facsimile". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh T.43`). For the data structure, refer to [the
technical details](t43-details.md).

## Summary

T.43 sends colour and grey-scale pages with no loss of data. It
divides the image into bit-planes and codes them with JBIG
([T.82](t82.md)).

- There are three types of image:
  - One bit for each colour (RGB, CMY or CMYK).
  - A palette: indices into a table of CIELAB colours.
  - Continuous tone: L*, or L*, a* and b* (T.42).
- A continuous-tone sample is Gray coded first. A small change of a
  sample then changes few bit-planes, and JBIG codes the planes
  better.
- The data is a BCIE. It has a header with entries (G3FAX0, an
  optional palette G3FAX3, the end ECIH). Then it has one JBIG BIE with
  all the planes, and an end marker.
- The planes go in stripe interleave (the basic method) or plane
  interleave (negotiated).

## Where T.43 is used

Some colour fax machines use T.43 for pages with few colours, such as
charts and maps. On these pages, T.43 is smaller than JPEG and has no
loss.

## Related standards

- [T.82](t82.md): the coding of the planes.
- [T.42](t42.md): the CIELAB colour space.
- [T.30](t30.md): negotiates T.43 with DIS/DCS bits 36 and 37.
- [T.44](t44.md): can use T.43 for its image layers.

## T.43 in D-Modem

`dsp/t43.cpp` codes and decodes all the T.43 image types. The T.30
machine sends a page with few colours or grey levels in T.43, when
the far end supports it.
