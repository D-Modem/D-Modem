# V.110: V-series terminals on an ISDN

This page describes ITU-T Recommendation V.110 (02/2000), "Support by
an ISDN of data terminal equipments with V-series type interfaces". It
is our own description. It is not a copy of the Recommendation. For the
normative text, refer to the Recommendation (`docs/specs/fetch.sh
V.110`). For the frames, the codes and the procedures, refer to
[the technical details](v110-details.md).

## Summary

V.110 tells how a terminal adapter (TA) puts the data of a V-series
terminal into a 64 kbit/s B-channel of an ISDN.

- **RA0** changes an asynchronous user rate to the next synchronous
  rate of 2^n × 600 bit/s. It adds stop elements.
- **RA1** puts the synchronous bits into frames of 80 bits. The
  frames go at 8, 16, 32 or 64 kbit/s (the intermediate rate).
- **RA2** puts the intermediate rate into the first 1, 2, 4 or 8 bits of
  each octet of the B-channel. The other bits are ones.
- Each frame has a 17-bit alignment pattern, 48 data bits (D), status
  bits (S and X) and seven E bits. E1 to E3 give the user rate.
- A TA sends frames with S and X OFF until it has frame
  synchronisation. Then it sends S and X ON, and the data flows.
- 48000 and 56000 bit/s have their own adaption, with no 80-bit frames.

## Where V.110 is used

ISDN terminal adapters in Europe and Japan used V.110. GSM circuit
switched data also uses V.110 frames in the network, so an ISDN data
call can reach a GSM data terminal.

## Related standards

- [X.75](x75.md): a link protocol that can go on V.110 frames, or on the
  full 64 kbit/s.
- [V.120](v120.md): the other rate adaption for ISDN, with HDLC frames.
- X.30: the same frames for X.21 terminals.
- 3GPP TS 27.007: the `AT+CBST` command that selects the rate.

## V.110 in D-Modem

`dsp/v110.cpp` makes and synchronises the frames, and the clear channel
pump (`dsp/dp_clear.cpp`) runs them. `AT+CBST` selects the rate. For
how to use it, refer to [ISDN: technical details](../isdn-details.md#atcbst-v110-rate-adaption).
