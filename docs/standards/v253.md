# V.253: AT commands for voice

This page describes ITU-T Recommendation V.253 (02/98), "Control of voice
related functions in a DCE by an asynchronous DTE". It is our own
description. It is not a copy of the Recommendation. For the normative
text, refer to the Recommendation (`docs/specs/fetch.sh V.253`). For the
commands, the events and the codes, refer to [the technical
details](v253-details.md).

## Summary

V.253 lets a computer use a modem as a telephone: an answering machine,
a voice mail system or a call announcer.

- `AT+FCLASS=8` puts the modem in voice mode.
- `AT+VLS` connects the voice engine to the line, to a handset or to
  nothing.
- `AT+VTX` plays the samples that the computer sends. `AT+VRX` records
  the samples from the line. `AT+VTR` does the two at the same time.
- `AT+VSM` sets the format of the samples, for example 8-bit PCM at
  8000 samples/s, or ADPCM.
- `AT+VTS` sends DTMF digits and tones.
- In the stream of samples, `<DLE>` (10h) starts a code. From the modem,
  a code tells of an event: a DTMF digit, a busy tone, a ring, silence.
  From the computer, a code stops the playback or the recording.
- `AT+VCID` sets the caller ID reports, and `AT+VRID` gives the caller
  ID of the last call again.

## Where V.253 is used

Voice programs such as vgetty and many answering machine programs use
V.253. It was first a TIA standard (IS-101).

## Related standards

- V.250: the syntax of the commands.
- V.251: the AT commands for V.8.
- T.31 and T.32: the fax commands, for a call that changes from voice
  to fax.
- G.711 and G.726: sample formats that `AT+VSM` can select.

## V.253 in D-Modem

`core/at.cpp` has the commands. `core/modem.cpp` and the voice engine in
`dsp/` play, record and detect the events. The commands are described in
[the AT commands](../at_commands.pdf).
