# V.76: a multiplexer on LAPM

This page describes ITU-T Recommendation V.76 (08/96), "Generic
multiplexer using V.42 LAPM-based procedures". It is our own
description. It is not a copy of the Recommendation. For the normative
text, refer to the Recommendation (`docs/specs/fetch.sh V.76`). For the
frames, the procedures and the parameters, refer to [the technical
details](v76-details.md).

## Summary

V.76 shares one HDLC link among many data link connections (DLCs). It
uses the frames and the procedures of [V.42](v42.md) LAPM.

- The DLCI in the address octet identifies the DLC. The initiator takes
  DLCIs from 0 up. The responder takes DLCIs from 63 down.
- Each DLC has its mode. ERM (error recovery mode) is LAPM: I frames,
  RR, RNR and REJ. UNERM (unacknowledged mode) uses UI frames, with no
  recovery.
- SABME opens a DLC and DISC closes it. Their information field carries
  the user data of the control entity ([V.75](v75.md)).
- XID frames carry the parameters.
- The default parameters for V.70 are in Annex C: one-octet addresses,
  a 16-bit FCS, REJ recovery, k 15 and N401 128.
- Annex A adds real-time DLCs, with suspend and resume of a frame.

## Where V.76 is used

V.70 DSVD terminals use V.76 for their voice and data channels.

## Related standards

- [V.42](v42.md): LAPM, the procedures of each ERM DLC.
- [V.70](v70.md) and [V.75](v75.md): DSVD and its control entity.
- ISO/IEC 13239: HDLC.
