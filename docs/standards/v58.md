# V.58: the management information model of a DCE

This page describes ITU-T Recommendation V.58 (09/94), "Management
information model for V-series DCEs". It is our own description. It is
not a copy of the Recommendation. For the normative text, refer to the
Recommendation (`docs/specs/fetch.sh V.58`). For the objects and the
test functions, refer to [the technical details](v58-details.md).

## Summary

V.58 gives the managed objects of a V-series modem, for a
telecommunications management network (TMN). A management system can
read and change the attributes of each object. It can start actions, and
it can get notifications.

- The objects come from the generic objects of M.3100. The notation is
  that of X.722 (GDMO and ASN.1).
- There are eight object classes: call control, data compression, the
  DCE, the DTE interface, error control, the line interface, the signal
  converter and the test function.
- V.58 does not give the protocol that carries the management data.

## Where V.58 is used

V.250 clause 6.7 made the test function object of V.58 into AT
commands (`+T` commands). V.59 adds objects for diagnostic information.

## Related standards

- [V.250](v250.md): the `+T` commands.
- [V.54](v54.md): the loops that the test function controls.
- [V.52](v52.md): the 511-bit pattern of the error rate test.
- V.59: the diagnostic objects.
