# V.18: text telephones

This page describes ITU-T Recommendation V.18 (11/2000), "Operational
and interworking requirements for DCEs operating in the text telephone
mode". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh V.18`). For the signals, the timers and the
character codes, refer to [the technical details](v18-details.md).

## Summary

V.18 lets a modem talk to text telephones of many types. Deaf persons
and persons who cannot hear well use text telephones on the telephone
network.

- V.18 has its own mode between two V.18 modems: V.21 at 300 bit/s, 8
  data bits (Annex G).
- It also connects to the text telephones that were in use before it:
  - the 5-bit (Baudot) TTYs at 45.45 or 50 bit/s (Annex A),
  - DTMF text telephones (Annex B),
  - EDT at 110 bit/s (Annex C),
  - Bell 103 at 300 bit/s (Annex D),
  - the V.23 Videotex terminals, Minitel and Prestel (Annex E),
  - the V.21 text telephones of the Nordic countries and the UK
    (Annex F).
- Automoding finds the mode of the remote text telephone. The calling
  modem sends CI and XCI. The answering modem listens. If the caller
  sends nothing, the answering modem sends probes in each mode.
- A text telephone call does not end when no signal is on the line.

## Where V.18 is used

Text relay services, textphones and the programs that answer text
calls use V.18. V.250 gives the commands `+MV18S`, `+MV18R`,
`+MV18AM` and `+MV18P`.

## V.18 in D-Modem

`AT+MS=V18` (or `AT+MV18S=1`) starts automoding. `+MS=BAUDOT`, `EDT`,
`DTMF`, `V21TXT` and `V23TXT` select one mode. The code is
`dsp/dp_text.cpp`.
