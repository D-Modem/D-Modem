# G.729: speech coding at 8 kbit/s

This page describes ITU-T Recommendation G.729 (06/2012), "Coding of
speech at 8 kbit/s using conjugate-structure algebraic-code-excited
linear prediction (CS-ACELP)", with Annex A and Annex B. It is our own
description. It is not a copy of the Recommendation. For the normative
text, refer to the Recommendation (`docs/specs/fetch.sh G.729`). For the
frame and the parameters, refer to [the technical
details](g729-details.md).

## Summary

G.729 codes speech at 8 kbit/s. Each frame has 10 ms of speech (80
samples at 8000 Hz) and gives 80 bits (10 octets).

- The encoder finds a linear prediction filter for each frame. It sends
  the filter as line spectral pairs (LSP).
- Each frame has two subframes of 5 ms. For each subframe, the encoder
  finds the pitch (the adaptive codebook), four pulses (the fixed
  codebook) and two gains.
- The decoder makes the excitation again, filters it, and applies a
  postfilter.
- If a frame is lost, the decoder conceals it from the last good
  frames.
- **Annex A** is a coder with less complexity. Its bit stream is the
  same as the bit stream of G.729.
- **Annex B** adds silence compression: a voice activity detector
  (VAD), discontinuous transmission (DTX) and comfort noise. In silence
  the encoder sends a 2-octet SID frame only when the noise changes.

## Where G.729 is used

V.70 DSVD modems use G.729 Annex A for the voice channel. Voice over IP
also uses G.729.

## Related standards

- [V.70](v70.md): DSVD, which uses Annex A.
- [V.75](v75.md): the audio header, which marks the SID frames.
- RFC 3551: the G729 payload for RTP, with the same order of the bits.
