# T.45: run-length colour encoding

This page describes ITU-T Recommendation T.45 (02/2000), "Run-length
colour encoding". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh T.45`). For the data format, refer to [the
technical details](t45-details.md).

## Summary

T.45 codes a list of colour values (or palette indices) as runs.

- A 6-octet header gives the number of components in a value, the
  octets in a component and the number of values.
- Each run is a length (1 or 3 octets) and one value. The run tells
  how many times the value occurs in sequence.
- The data ends when the runs give all the values.
- T.45 does not tell what the values mean. The colour space and the
  palette come from a different part of the data.

## Where T.45 is used

T.44 mode 4 uses T.45 for "colour tags". The mask of a stripe is in
JBIG2, which draws each character as a symbol. The foreground is then
not an image. It is one colour for each symbol, in the sequence of the
symbols, coded with T.45. Text in a small number of colours then needs
only some octets for its colour.

## Related standards

- [T.44](t44.md): mode 4 (Annex B) uses T.45 for the foreground layers.
- T.88 (JBIG2): codes the mask that the colour tags refer to.
