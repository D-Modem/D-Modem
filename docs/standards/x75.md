# X.75: LAPB on an ISDN data call

This page describes ITU-T Recommendation X.75 (10/96), "Packet-switched
signalling system between public networks providing data transmission
services". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh X.75`). For the frames, the procedures and the
parameters, refer to [the technical details](x75-details.md).

## Summary

X.75 connects two packet networks. Its link level, the single link
procedure (SLP), is LAPB from X.25. ISDN equipment uses this link level
on a 64 kbit/s B-channel to send data with no errors (T.90, CAPI B2
protocol 0).

- The data goes in HDLC frames with a 16-bit frame check sequence (FCS).
- Each end has an address: A (`03h`) or B (`01h`). Commands go to the
  address of the remote end. Responses go with the address of the local
  end.
- SABM starts the link. UA accepts it. DISC ends the link.
- Each I frame has a send number N(S) and a receive number N(R), modulo
  8. Up to k frames (7) can be sent before an acknowledgement.
- RR acknowledges the frames. RNR tells that the receiver is busy. REJ
  asks for the frames again, from N(R).
- When timer T1 expires, the end polls the other end with the P bit, up
  to N2 times. Then it resets the link with SABM.
- An error that a retransmission cannot correct gives FRMR. The other
  end then resets the link.

## Where X.75 is used

ISDN terminal adapters, CAPI cards and isdn4linux use the X.75 link
level for data calls on a B-channel. Many German ISDN BBSes and mailers
used it.

## Related standards

- X.25: LAPB, from which X.75 takes its link level.
- ISO/IEC 13239: HDLC, the frames of LAPB.
- [V.42](v42.md): LAPM, a similar procedure for modems.
- V.120: a different link level for ISDN, with the frames of LAPD.
- T.90: the use of X.75 for telematic services on ISDN.

## X.75 in D-Modem

`link/lapb.cpp` has the single link procedure in basic mode (modulo 8).
`AT+B2=0` selects it on a clear channel. The implementation is described
in [ISDN: technical details](../isdn-details.md#x75).
