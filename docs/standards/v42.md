# V.42: error correction

This page describes ITU-T Recommendation V.42 (03/2002), "Error-correcting
procedures for DCEs using asynchronous-to-synchronous conversion". It is
our own description. It is not a copy of the Recommendation. For the
normative text, refer to the Recommendation (`docs/specs/fetch.sh V.42`).
For the frames, the parameters and the procedures, refer to [the
technical details](v42-details.md).

## Summary

V.42 makes the data from the computer arrive with no errors. The modem
puts the characters in frames. The other modem checks each frame. It
asks again for a frame that is lost or damaged.

- The protocol is LAPM (Link Access Procedure for Modems). It uses HDLC
  frames with a frame check sequence (FCS) of 16 bits or 32 bits.
- At the start, a detection phase finds if the other modem has V.42.
  The originator sends a detection pattern (ODP), and the answerer
  replies with its pattern (ADP). Then LAPM starts. If there is no
  reply, the modems send the characters with no error correction.
- XID frames negotiate the parameters. These are the window size (k),
  the maximum frame length (N401), the 32-bit FCS and the data
  compression (V.42 bis or V.44).
- Each I frame has a sequence number. The receiver acknowledges the
  frames that it gets. When a frame is missing, it sends REJ, and the
  sender sends the frames again.
- A modem can also send a break from the DTE to the other modem.

## Where V.42 is used

Most modems from V.22 bis to V.92 have V.42. The 1996 edition also had
MNP 4 (Annex A) for older modems. The 2002 edition removed it.

## Related standards

- [V.42 bis](v42bis.md) and [V.44](v44.md): the data compression on
  LAPM.
- V.14: the asynchronous characters when there is no error correction.
- ISO/IEC 13239: HDLC, the frames of LAPM.
- V.76: LAPM on each channel of a multiplexer.

## V.42 in D-Modem

`link/lapm.cpp` has LAPM, and `link/hdlc.cpp` has the HDLC framing and
the detection phase. `link/mnp.cpp` has MNP for modems with no LAPM. The
implementation is described in [the data link layer](../link.md) and
[its technical details](../link-details.md).
