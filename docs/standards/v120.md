# V.120: rate adaption with statistical multiplexing

This page describes ITU-T Recommendation V.120 (10/96), "Support by an
ISDN of data terminal equipment with V-series type interfaces with
provision for statistical multiplexing". It is our own description. It
is not a copy of the Recommendation. For the normative text, refer to
the Recommendation (`docs/specs/fetch.sh V.120`). For the frames and
the procedures, refer to [the technical details](v120-details.md).

## Summary

V.120 carries the data of a terminal in HDLC frames on an ISDN
B-channel. It does not use the fixed frames of V.110.

- The link layer is the LAPD of Q.921 and Q.922, with a two-octet
  address. The address holds a logical link identifier (LLI). The
  default LLI is 256.
- Each LLI is one logical link. Many links can share one B-channel.
- Each frame of user data starts with a terminal adaption header (H).
  The header tells the break, the errors and the segments.
- An optional control state octet (CS) carries the state of the V.24
  circuits.
- The link can use the multiple frame mode (I frames, with
  acknowledgement and recovery), or the unacknowledged mode (UI
  frames).
- There are three modes: asynchronous, synchronous HDLC, and bit
  transparent.

## Where V.120 is used

ISDN terminal adapters in North America used V.120. Most ISDN cards for
personal computers can also use it.

## Related standards

- [V.110](v110.md): the other rate adaption for ISDN, with fixed frames.
- [X.75](x75.md): LAPB on an ISDN data call.
- Q.921 and Q.922: the data link layer.
- Q.931: the call set-up, with the low layer compatibility element.

## V.120 in D-Modem

`AT+B2=9` selects V.120. The link is in `link/lapb.cpp`. For how to use
it, refer to [ISDN: technical details](../isdn-details.md#atb29-v120).
