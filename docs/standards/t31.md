# T.31: Class 1 fax AT commands

This page describes ITU-T Recommendation T.31 (08/95), "Asynchronous
facsimile DCE control, service class 1". It is our own description. It
is not a copy of the Recommendation. For the normative text, refer to
the Recommendation (`docs/specs/fetch.sh T.31`). For the commands, the
parameters and the timers, refer to [the technical details](t31-details.md).

## Summary

T.31 gives the AT commands that let fax software on a computer use a
modem as a Group 3 fax DCE. The software does the procedure of
[T.30](t30.md) and the coding of [T.4](t4.md). The modem does the
modulation and the HDLC framing.

- `AT+FCLASS=1` selects Class 1.
- `+FTH` and `+FRH` send and receive HDLC frames, usually on V.21
  channel 2 (`3`).
- `+FTM` and `+FRM` send and receive the page data and TCF on a fast
  modulation (for example `96`: V.29 at 9600 bit/s).
- `+FTS` and `+FRS` send silence, or wait for silence.
- The data on the serial port uses `<DLE>` codes. `<DLE><ETX>` ends a
  stream. `<DLE><DLE>` is one `<DLE>` in the data.
- Parameters control adaptive reception (`+FAR`), the time for a
  carrier loss (`+FCL`), `<DLE><SUB>` (`+FDD`) and the DTE inactivity
  timer (`+FIT`).

## Where T.31 is used

Fax software such as HylaFAX, efax and many Windows fax programs use
Class 1. Class 1 lets the software use the fax features that the modem
does not know, for example ECM.

## Related standards

- [T.30](t30.md): the procedure that the software does.
- [T.4](t4.md): the coding of the page data.
- [V.21](v21.md), [V.27 ter](v27ter.md), [V.29](v29.md) and
  [V.17](v17.md): the modulations.
- [V.250](v250.md) (formerly V.25 ter): the syntax of the AT commands.
- T.32: Class 2 and Class 2.0, where the modem does T.30.

## T.31 in D-Modem

`dsp/fax_class1.cpp` has the Class 1 engine. `core/at.cpp` has the
commands. Class 1.0 adds V.34 half-duplex with `+F34`. Class 1 also
operates on T.38.
