# H.245: control messages for multimedia

This page describes ITU-T Recommendation H.245, "Control protocol for
multimedia communication". D-Modem uses only the messages that V.75
lists. It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh H.245`). For the messages and the encoding, refer
to [the technical details](h245-details.md).

## Summary

H.245 gives the messages that two multimedia terminals send to control
a call.

- The messages are in ASN.1. The encoding is the aligned packed
  encoding rules (PER) of X.691.
- A MultimediaSystemControlMessage is a request, a response, a command
  or an indication.
- OpenLogicalChannel opens a channel for audio, video or data. Its
  answer is OpenLogicalChannelAck or OpenLogicalChannelReject.
- CloseLogicalChannel closes a channel.
- TerminalCapabilitySet tells what the terminal can do.
- Later editions add components with the extension marker. An old
  decoder skips them.

## Where H.245 is used

H.324 (video telephones on the GSTN), H.323 (multimedia on IP) and V.70
DSVD (through V.75) use H.245.

## Related standards

- [V.75](v75.md): the H.245 messages of DSVD.
- X.691: the packed encoding rules.

## H.245 in D-Modem

`link/h245.cpp` codes the messages that V.75 uses. The implementation
