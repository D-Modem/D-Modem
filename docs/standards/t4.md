# T.4: Group 3 fax pages

This page describes ITU-T Recommendation T.4 (07/2003),
"Standardization of Group 3 facsimile terminals for document
transmission". It is our own description. It is not a copy of the
Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh T.4`). For the codes and the line format, refer
to [the technical details](t4-details.md).

## Summary

T.4 tells how a Group 3 fax machine scans a page and codes it for the
telephone line.

- A page is a set of scan lines, from the top to the bottom. Each line
  has 1728 black and white picture elements (pels) on 215 mm. Wider
  pages (2048 and 2432 pels) and more pels are options.
- The standard vertical resolution is 3.85 lines/mm. 7.7 lines/mm
  (fine) and 15.4 lines/mm are options. Inch-based resolutions are
  also options.
- The modified Huffman code (MH) codes each line as runs of white and
  black. It is mandatory.
- The modified READ code (MR) codes most lines against the line above
  them. It is an option.
- On the line, an EOL code word comes before the first line and after
  each line. Six EOLs (RTC) end the page.
- Fill bits make each line take a minimum time, for the printer of the
  receiver.
- The annexes give the error correction mode (ECM), file transfer,
  character mode, and the colour and grey-scale modes. These modes use
  other codes, for example [T.6](t6.md) (MMR) and T.82/T.85 (JBIG).

## Where T.4 is used

All Group 3 fax machines use T.4 for the page data. T.30
gives the procedure of the call that carries these pages. TIFF files
for fax (TIFF-F) also use the MH, MR and MMR codes.

## Related standards

- T.30: the procedure of the fax call, and the negotiation of the
  options of T.4.
- [T.6](t6.md): the MMR code, used by T.4 with ECM.
- T.82 and T.85: JBIG coding, used by T.4 with ECM.
- T.42, T.43 and T.44: colour and grey-scale coding.
- [V.27 ter](v27ter.md), [V.29](v29.md), [V.17](v17.md) and
  [V.34](v34.md): the modulations of the page data.

## T.4 in D-Modem

`dsp/t4.cpp` has the MH, MR and MMR encoders and decoders. A fax call
sends pages in MR when the remote fax machine accepts MR, and in MH
if not. With ECM, it sends MMR when the remote accepts MMR. It
receives MH, MR and MMR at 1728 pels, standard or fine. The TIFF
reader decodes MH, MR and MMR pages.
