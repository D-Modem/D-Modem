# V.29: 9600 bit/s for leased lines and fax

This page describes ITU-T Recommendation V.29 (11/1988), "9600 bits per
second modem standardized for use on point-to-point 4-wire leased
telephone-type circuits". It is our own description. It is not a copy of
the Recommendation. For the normative text, refer to the Recommendation
(`docs/specs/fetch.sh V.29`). For the signal, the synchronizing signal
and the timing, refer to [the technical details](v29-details.md).

## Summary

V.29 sends data at 9600 bit/s, with fallback rates of 7200 bit/s and
4800 bit/s. It was made for 4-wire leased circuits of special quality.

- The carrier is 1700 Hz. The modem sends 2400 symbols each second.
- Each symbol has a phase change and an amplitude. At 9600 bit/s, each
  symbol carries four bits. This is combined amplitude and phase
  modulation, an early form of QAM.
- A scrambler makes the data random.
- The receiver has an adaptive equalizer. If the equalizer loses the
  signal, the modem asks the far modem to send a new synchronizing
  signal.
- An optional multiplexer can put channels of 7200, 4800 and 2400 bit/s
  into one stream.

## Where V.29 is used

V.29 was made for leased lines. But its main use now is Group 3 fax.
T.30 uses V.29 at 9600 bit/s and 7200 bit/s for the page data, in half
duplex on the switched network. V.29 does not give rules for the
switched network (Note 1 of clause 1). The fax standards supply them.

## Related standards

- V.27: V.29 uses the same 8-phase changes.
- V.26 (alternative A): the phase changes at 4800 bit/s.
- [V.27 ter](v27ter.md): the slower fax modulation.
- [V.17](v17.md): the faster fax modulation.
- T.30: the fax procedure.

## V.29 in D-Modem

`dsp/fax_modems.cpp` has the V.29 transmitter and receiver. The fax code
uses them for the pages (`AT+FTM=72` and `AT+FTM=96` in Class 1).
`dsp/dp_4wire.cpp` uses them as a data pump for 4-wire leased lines
(`AT+MS=V29`), duplex with a continuous carrier, at the three rates.
