# T.434: binary file transfer

This page describes ITU-T Recommendation T.434 (04/99), "Binary file
transfer format for the telematic services". It is our own
description. It is not a copy of the Recommendation. For the normative
text, refer to the Recommendation (`docs/specs/fetch.sh T.434`). For the
data format, refer to [the technical details](t434-details.md).

## Summary

T.434 sends files with their names and attributes, for example over a
Group 3 fax call with ECM (BFT).

- The data is a BINARY-DATA message in ASN.1, coded with the basic
  encoding rules (BER, X.690).
- The message has one or more files. Each file is a list of
  attributes. Examples are the protocol version, the file name, the
  date of the last change, the size, the MIME type and the file data.
- Most attributes come from the FTAM file attributes (ISO 8571).

## Where T.434 is used

A fax machine or fax server that supports BFT can send files, not only
pages. Few fax machines support it.

## Related standards

- [T.30](t30.md): negotiates BFT with DIS/DCS bit 53, and sends the
  message in ECM.
- [T.32](t32.md): the Class 2 commands for BFT.

## T.434 in D-Modem

`dsp/t434.cpp` codes and decodes the BINARY-DATA message. The T.30
machine sends and receives files with BFT.
