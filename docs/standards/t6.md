# T.6: the MMR code for fax pages

This page describes ITU-T Recommendation T.6 (11/88), "Facsimile coding
schemes and coding control functions for Group 4 facsimile apparatus".
It is our own description. It is not a copy of the Recommendation. For
the normative text, refer to the Recommendation (`docs/specs/fetch.sh
T.6`). For the code, refer to [the technical details](t6-details.md).

## Summary

T.6 gives the modified modified READ code (MMR) for black and white
pages.

- Every line is coded in two dimensions, against the line above it.
  The reference line for the first line is an imaginary white line.
- The modes are the pass, vertical and horizontal modes of
  [T.4](t4.md) MR. The code words are the same.
- There are no EOLs and no fill between the lines.
- EOFB (two EOLs) ends the page.
- The uncompressed mode is an option.

Because there is no EOL, an error in one line changes all the lines
after it. Thus Group 3 uses MMR only with the error correction mode.

## Where T.6 is used

Group 4 fax uses T.6 on digital networks. Group 3 fax can use it with
ECM (T.4 4.3). TIFF files for fax use it as compression 4.

## Related standards

- [T.4](t4.md): MH and MR. T.6 uses the code tables and the
  two-dimensional modes of MR.
- T.30: the DIS bit for MMR (bit 31) and ECM.
- T.4 Annex A: the error correction mode.

## T.6 in D-Modem

`dsp/t4.cpp` decodes MMR pages from TIFF files (compression 4). A fax
call does not send or receive MMR: the DIS does not offer it.
