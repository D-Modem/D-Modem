# Acknowledgements

Aon's Cyber Labs made D-Modem in 2021. They published it with the article [Introducing D-Modem: A Software SIP Modem](https://www.aon.com/cyber-solutions/aon_cyber_labs/introducing-d-modem-a-software-sip-modem/).  This project started from their idea and their code. Their code sent the audio of slmodemd on a socket, and their d-modem program was a SIP user agent next to it.  New code now replaces their code. We wrote the SIP user agent, `frontend/dmodemd/sip.cpp`, again from a specification of its functions.  The modem daemon started as `slmodemd` of Smart Link (from the sl-modem-daemon package of Debian). New code replaces its code also. We wrote this code again from specifications of its functions.  [libre](https://github.com/baresip/re) does the SIP processing.
